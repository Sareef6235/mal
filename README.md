# NoorOps Premium Home Page UI

A from-scratch responsive cyber glassmorphism + neumorphism home page concept for a secure Islamic education management platform.

## Included UI areas

- Premium sticky navigation with responsive slide menu and theme switcher.
- Hero with animated counters, Lottie security lock, Telegram CTA, and floating glass cards.
- Feature matrix for plans, receipts, quizzes, Telegram OTP, PDFs, students, Ustads, PWA, and security.
- Realistic admin dashboard preview with Chart.js, finance cards, tables, progress bars, notifications, and PDF export.
- Security, FAQ, Terms & Conditions, Privacy Policy, Contact, modals, toasts, print styles, particles, and mobile bottom navigation.

## Run locally

Open `index.html` directly, or serve the folder with a local static server:

```bash
python3 -m http.server 8080
```
