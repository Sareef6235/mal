Frequently asked questions

Accordion answers for security, exports, Telegram verification, mobile support, and offline PWA behavior.

How secure is the system?

The interface presents secure login, OTP modals, session timers, inactive tab blur, secure watermarks, role-aware navigation, and audit-friendly activity logs.

Can receipts be exported?

Yes. The dashboard includes receipt preview, print preview, html2canvas capture, and jsPDF export actions for finance reporting.

Is Telegram verification required?

Telegram verification can be required for sensitive workflows such as quiz verification, login hardening, or account recovery depending on policy.

Does it support mobile?

Yes. The layout includes a collapsible sidebar, mobile bottom navigation, floating action button, full-screen modals, and card-style table conversion.

Is offline PWA supported?

Yes. A web manifest, service worker, install prompt hook, app theme color, and offline fallback page support installable app behavior.
