FAQ

Answers before onboarding.

How secure is the system?

The UI models layered protection with OTP prompts, session warnings, copy restriction notices, watermark overlays, and device-health panels.

Can data be exported?

Yes. The design includes secure PDF export, print preview, professional receipt tables, and A4-optimized print styling.

Is Telegram required?

Telegram is presented as the recommended verification channel for sensitive actions, with an OTP modal for approvals.

Does it support Malayalam?

Yes. Typography includes Noto Sans Malayalam and print styles are tuned for Malayalam document rendering.

Can admins print reports?

Admins can use the print preview modal and print/PDF actions designed into the dashboard preview.

Does it work as PWA?

The responsive UI includes mobile bottom navigation, touch-sized controls, sticky actions, and app-like modal sheets.
