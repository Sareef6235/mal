FAQ

Fast answers for administrators, finance teams, and secure quiz reviewers.

How secure is the system?

The UI includes secure session modals, focus-loss blur, OTP verification, role access badges, device restrictions, activity logging, and access-denied flows.

Can receipts be exported?

Yes. Receipt previews support print actions and PDF export powered by jsPDF and html2canvas integration points.

Is Telegram verification required?

The interface supports Telegram verification as a premium security option for high-risk quiz or admin workflows.

Does it support mobile?

Yes. The sidebar collapses, tables become mobile cards, touch targets are enlarged, and bottom navigation is shown on phones.

Is offline PWA supported?

Yes. The manifest and service worker provide install prompts, app metadata, theme color, and an offline fallback shell.
