Islamic Madrasa / School Management + LMS + Attendance + Monthly Planning System.

== Description ==
Madrasa provides role-based LMS administration, student and teacher records, courses, lessons, attendance, exams, results, certificates, monthly plans, REST endpoints, shortcodes, settings, and PWA support.

== Installation ==
1. Upload the madrasa-lms-pro folder to wp-content/plugins.
2. Activate the Madrasa plugin.
3. Open the Madrasa admin menu.
