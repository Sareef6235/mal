Privacy-first admin design

Privacy Policy

AstraEdu is designed around minimal access, visible security state, and privacy-aware education administration workflows.

Secure Data Storage

Finance, receipt, plan, quiz, and user records should be stored in protected systems using encryption, backups, and controlled administrative access.

User Verification

Login, Telegram OTP, and secure review experiences verify that a user is authorized before sensitive records or quiz review data is displayed.

Session Management

Session timers, auto logout warnings, inactive-tab blur, and access denied popups reduce exposure on shared or unattended devices.

Role-based Permissions

Access should be limited by role, including admin, finance, teacher, reviewer, and student scopes, so each person sees only required tools.

Activity Logging

Approvals, exports, restores, deletions, OTP events, and restricted access attempts should be logged for review and accountability.

Device Restrictions

Device checks and secure watermarks discourage unauthorized sharing, screenshots, and use from unmanaged devices.
